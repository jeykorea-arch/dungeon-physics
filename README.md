# 던전 앤 피직스

고2 물리학 수업용 2D 픽셀 RPG입니다. 세계의 법칙이 오개념대로 뒤틀린 저주를, 이안과 가론이 '진실의 원'에서 실험으로 증명해 되돌립니다. 인터넷 없이 실행됩니다.

- 1막 힘과 에너지 (1-1 ~ 1-6)
- 2막 번개의 탑: 전기와 자기 (2-1 ~ 2-6)
- 3막 빛의 심연: 빛과 물질 (3-1 ~ 3-6, 최종 보스, 엔딩)

## 실행하는 법

1. 이 `game` 폴더를 통째로 복사합니다 (USB, 학교 PC 바탕화면 어디든 괜찮습니다. 폴더 크기 약 300 MB).
2. 폴더 안의 **`index.html`을 더블클릭**합니다. 크롬이나 엣지에서 열립니다.
   - 다른 프로그램(메모장 등)으로 열리면: `index.html`을 마우스 오른쪽 클릭 → 연결 프로그램 → Chrome 또는 Edge.
3. 제목 화면에서 "처음부터"를 누르면 소리가 나기 시작합니다.

- 화면 크기는 창에 맞춰 저절로 줄고 늘어납니다. 크게 보려면 F11(전체 화면).
- 진행 상황은 그 컴퓨터의 브라우저에 저장됩니다. 다른 컴퓨터에서는 처음부터입니다.

# 학생용: 조작법

방마다 화면 오른쪽 아래에 그 방의 키가 적혀 있고, 위쪽 "목표" 줄에 지금 할 일이 나옵니다. 물체에 다가가면 물체 위에 키 안내가 뜹니다.

## 언제나 쓰는 키

| 키 | 하는 일 |
|---|---|
| ← → | 걷기 |
| Z | 실험(진실의 원 안에서), 살펴보기, 들기·내려놓기 |
| X | 공격·던지기 |
| Space 또는 클릭 | 대사 넘기기 |
| M | 마법서 |
| T | 결과판 (전투·실험 기록) |
| R | 이 방 처음부터 |
| N 또는 오른쪽 위 버튼 | 소리 켜기·끄기 |

## 1막

| 키 | 하는 일 |
|---|---|
| Space | 출발·떨어뜨리기 (방에 따라) |
| Tab | 이안 ↔ 가론 바꾸기 (두 사람이 있는 방) |

## 2막

| 키 | 하는 일 |
|---|---|
| C | 문지르기 (2-1) · 코일 돌리기 (2-6) |
| V | 자석 갈고리·자석 장갑 (2-4) · 전자석 함정 켜기·끄기 (2-5) |
| X 길게 누르기 | 축전기 상자에 모으기 → 떼면 한꺼번에 쏘기 (2-3, 2-6 마지막 일격) |
| Q | 번개 지팡이 직렬/병렬 (2-2) · 함정 전류 방향 (2-5) |
| 1·2·3 (4·5·6) | 부품 고르기 화면 (2-5), 터치 석판 (2-3) |
| 마우스 | 회로판·전동기·스피커 화면에서 부품 누르기·끌어다 놓기 |

## 3막

|---|---|---|

# 교사용

## 교사용 메뉴 (오른쪽 위 "교사용" 버튼 또는 F1, 처음 한 번 코드 입력)

처음 열 때 숫자 코드를 묻습니다. 처음 코드는 `1905`이고, `js/config.js` 맨 위의 `teacherCode`에서 바꿀 수 있습니다. 창을 새로 고칠 때까지 다시 묻지 않습니다.

- **챕터 바로 가기**: 1막·2막·3막 탭에서 어느 방이든, 최종 보스 단계까지 바로 갑니다. 교사용으로 바로 가면 앞 방의 해설은 나오지 않습니다.
- **해방하기 / 저주 걸기**: 저주 상태와 진짜 법칙 상태를 같은 장면에서 바꿔 비교합니다.
- **눈금 끄기·켜기**, **속력 표시 끄기·켜기**: 화면의 m 눈금과 숫자판을 켜고 끕니다.
- **실험 전 답 숫자 보이기·숨기기**: 실험하기 전에도 답 숫자를 보여 줍니다. 3-3 전자 화면에는 이론 분포가 겹쳐 그려집니다.
- **마법서 시험 보기**, **물리 값 보기**(장면의 값과 실험 전 예측 기록), **저장 지우기**.

## 수업 흐름

장마다 ① 저주(오개념) 체험 → ② 진실의 원 실험 (실험 전 예측) → ③ 저주 해제·마법서 장 복원 → ④ 퍼즐과 전투 → ⑤ 마법서 시험.

## 챕터 안내와 성취기준 대응표

성취기준 칸은 비워 두었습니다. 학교에서 쓰는 2022 개정 교육과정 문서에 맞춰 적어 넣으세요.

| 장 | 방 | 저주(오개념) | 진짜 법칙 | 성취기준 |
|---|---|---|---|---|
| 1-1 | 시소 성 → 상자 저울 → 기울어진 탑 → 시소 다리 | 무게만 같으면 평형 | 돌림힘 = 힘 × 받침점까지 거리 | |
| 1-2 | 얼음 회랑 → 무너지는 다리 → 썰매 길 → 얼음 위 전투 | 밀지 않으면 멈춘다 | 관성, 가속도 = 힘 ÷ 질량 | |
| 1-3 | 얼음 호수 → 얼음 트롤 | 미는 쪽은 힘을 받지 않는다 | 작용·반작용, 운동량 보존 | |
| 1-4 | 광차 탑 → 바위 미끄러뜨리기 | 무거울수록 바닥에서 빠르다 | 역학적 에너지 보존 | |
| 1-5 | 거친 돌바닥 → 얼음 정령 | 에너지가 닳아 없어진다 | 마찰이 한 일 = 열 | |
| 1-6 | 상인 광장 → 상인 보스전 | 영원히 움직이는 기계 | 에너지 보존, 열기관 | |
| 2-1 | 탑 1층 실험실 | 전기력은 닿아야만 작용 | 전하는 떨어져 있어도 힘을 준다, 전기장 | |
| 2-2 | 탑 2층 등불의 방 | 많이 이을수록 다 밝아지고 선은 안 끊어진다 | 옴의 법칙, 전력, 직렬·병렬 | |
| 2-3 | 탑 3층 번개 문 | 전기는 저장할 수 없다 | 축전기 (판이 넓고 간격이 좁을수록 많이) | |
| 2-4 | 탑 4층 자석 금고 | 모든 금속이 자석에 붙는다 | 강자성·상자성·반자성 | |
| 2-5 | 승강기와 석상의 방 | 전기와 자기는 관계없다 | 전류의 자기 작용, 전동기, 스피커 | |
| 2-6 | 탑 꼭대기 봉화대 | 에너지는 전선으로만 전해진다 | 전자기 유도, 무선 전달 | |
| 3-1 | 어두운 줄무늬 벽 | 빛에 빛을 더하면 어디서나 밝아진다 | 빛의 간섭 | |
| 3-2 | 물웅덩이와 렌즈 | 빛은 어떤 물질에서도 똑바로만 간다 | 굴절, 겉보기 깊이, 볼록렌즈의 상 | |
| 3-3 | 작은 룬 문자의 방 | 빛은 파동이기만, 전자는 알갱이이기만 하다 | 빛과 물질의 이중성, 전자 현미경 | |
| 3-4 | 바코드 등불의 방 | 원자는 아무 에너지나 내놓는다 | 에너지 준위, 선스펙트럼 | |
| 3-5 | 수정 다리 | 전기는 어떤 물질이든 어느 방향이든 똑같이 흐른다 | 에너지띠, p-n 접합, 다이오드 | |
| 3-6 | 심연의 끝 → 최종 보스 | 시간은 똑같이 흐르고 빛도 따라잡는다 | 특수 상대성 이론 | |

최종 보스 1·2단계는 1막·2막 저주 복습입니다.

## 숫자·문구 바꾸기

물리 값은 모두 `js/config.js` 한 파일에 모여 있습니다. 메모장으로 열어 숫자만 바꾸고 저장한 뒤, 브라우저에서 F5를 누르면 바로 적용됩니다. 줄마다 `//` 뒤에 무엇인지 적혀 있습니다.

| 방 | config.js 안의 이름 |
|---|---|
| 1-1 시소 성 · 상자 저울 · 기울어진 탑 · 시소 다리 | `seesawGate` · `boxScale` · `tower` · `seesawBridge` |
| 1-2 얼음 회랑 · 무너지는 다리 · 썰매 길 · 얼음 위 전투 | `iceCorridor` · `collapsingBridge` · `sledPath` · `iceCombat` |
| 1-3 얼음 호수 · 얼음 트롤 | `iceLake` · `iceTroll` |
| 1-4 광차 탑 · 바위 미끄러뜨리기 | `minecart` · `rockRoll` |
| 1-5 거친 돌바닥 · 얼음 정령 | `roughFloor` · `iceSpirit` |
| 1-6 상인 광장 · 상인 보스전 | `merchantPlaza` · `merchantBoss` |
| 2-1 ~ 2-6 | `act2` 안의 `ch2_1` ~ `ch2_6` (공통 값 `electric` · `circuit` · `capacitor` · `magnetism` · `induction`) |
| 3-1 ~ 3-6, 최종 보스 | `act3` 안의 `ch3_1` ~ `ch3_6`, `finalBoss` (공통 값 `interference` · `optics` · `dots` · `spectrum` · `diode` · `relativity`) |

- 대사: `js/data/dialogue/` 폴더 (장마다 한 파일)
- 마법서 시험 문제: `js/data/exams.js`
- 최종 보스 저주 문장과 두 보기: `js/data/boss_curses.js`
- 실험 전 예측: `js/data/predictions.js`
- 크레딧: `js/data/credits.js`
- 1-6 기계 감정 퍼즐: `js/data/machine_quiz.js`

숫자를 바꾸면 퍼즐 정답도 함께 바뀌니, 바꾼 뒤 한 번 직접 해 보세요.

## 안 될 때

- 화면이 까맣게 나오거나 멈춤: F5(새로 고침). 그래도 안 되면 교사용 메뉴(F1) → 저장 지우기.
- 소리가 안 남: 화면을 한 번 클릭하거나 키를 한 번 누르면 납니다(브라우저가 자동 소리를 막기 때문).
- 너무 느림: 다른 탭·프로그램을 닫아 보세요.
